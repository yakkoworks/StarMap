## mdxファイルの自動整形

VSCodeに「Prettier」を導入し<br />
設定ファイルに以下を追記することでmdxの自動整形が行えるようになりました

```
	// settings.json
   "[mdx]": {
    "editor.autoIndent": "advanced",
    "editor.defaultFormatter": "esbenp.prettier-vscode",
    "editor.formatOnSave": true
  }
```

### 一部を自動整形の対象外とする

1行で書かないと,Astro Starlight側に正しく認識されないpタグ等の前には

```
  {/* <!-- prettier-ignore --> */}
```

を挟めば自動整形されなくなります<br />

<br />
複数行にわたる場合は
```
{/* <!-- prettier-ignore-start --> */}
自動整形から除外したい記述
{/* <!-- prettier-ignore-end --> */}
```
こうすればOKです
